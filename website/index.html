VERSION HISTORY

Quartz 2.0

A packaged Chromium/CEF engine and the first experimental extension support. Quartz 1.x is kept here as the original public WebView2 release line.

VERSION
  • 01
    Chromium/CEF engine

    Quartz now ships its own Chromium engine instead of depending on WebView2.

  • 02
    Unpacked extensions

    Manage compatible local Manifest V3 extension folders and persist them across restarts.

  • 03
    CEF-native downloads

    Download progress and actions remain inside the Quartz workspace through CEF callbacks.

  • 04
    Isolated private profiles

    Private windows use a separate in-memory Chromium request context.

  • 01
    First public installer

    Quartz Version 1.1.0 introduced the first downloadable Windows installer for the browser.

  • 02
    WebView2 browser shell

    The original release used Microsoft WebView2 with Chromium-based browsing, tabs, address/search, bookmarks, history, downloads, settings, and private mode.

  • 03
    Original Quartz basics

    Version 1 included the first custom Quartz UI direction, theme support, site information, and permission prompts.

  • 04
    Archived release

    Version 1 is kept for history while Version 2 is the recommended download. View the 1.1.0 release.
